# Changelog

All notable changes to this project are documented here.

## [0.2.0] - 2026-09-09

- Added Phoenix screenshots and technical repository metadata.

- Added an opt-in dependency-free hashed-vector retrieval baseline via `RETRIEVAL_BACKEND=vector`.
- Added production-readiness and model-risk documentation.

## [0.1.0] - 2026-09-09

- Initial production-inspired AI observability lab with FastAPI, OpenTelemetry, Phoenix, deterministic evaluations, prompt experiments, guardrails, and optional Dynatrace fan-out.

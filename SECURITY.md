# Security policy

This repository is an educational AI observability lab with fictional banking data. Do not use it as a production banking service or send real customer information to it.

## Reporting a vulnerability

Please do not open a public issue for a suspected secret, privacy issue, or exploitable bug. Contact the repository owner privately through the GitHub profile and include reproduction steps, affected files, and impact. Never include real credentials or personal data in a report.

The default configuration disables message-content capture and external providers. Keep credentials in environment variables and rotate any secret that may have been exposed.
